# Доход Врача — PWA

Учёт дохода врача в частной клинике.

## Запуск

1. Включите GitHub Pages в настройках репозитория (Settings → Pages → Source: main / root).
2. Откройте ссылку на телефоне и добавьте на главный экран.

Иконки нужно добавить в папку `icons/` вручную (icon-192.png и icon-512.png), если их ещё нет.
